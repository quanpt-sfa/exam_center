# Exam Version Delivery Profile API

Base path: `/api/v1`

Endpoints:
- GET `/master-data/exam-versions/{exam_version_id}/delivery-profile`
- PUT `/master-data/exam-versions/{exam_version_id}/delivery-profile`

Profile notes:
- `FILE_BASED` delivery is supported.
- `FILE_ARTIFACT` is the canonical paper artifact category for file-based delivery.
